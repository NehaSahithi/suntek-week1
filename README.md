# Week 1 JavaScript Practice

This repository contains beginner-to-intermediate JavaScript practice files organized by topic, focusing on array methods, object manipulation, and data handling.

## Folder Structure

- `array-operations/` – Exercises for working with arrays and basic object properties.
- `array-operations-adv/` – Advanced array assignments (e.g., cart processing, grading, payroll).
- `collections/` – Examples related to data types and object collections.
- `control statements/` – Logic involving conditionals and loops.

## JavaScript Functions Reference

Below is a summary of the core functions used in this practice set:

### 1. Array Operations
- **`filter()`**: Creates a new array with elements that pass a specific test.
- **`map()`**: Transforms each element in an array and returns a new array.
- **`reduce()`**: Aggregates array elements into a single value (sum, highest, etc.).
- **`find()`**: Returns the first element that matches a given condition.
- **`findIndex()`**: Returns the index of the first element that matches a given condition.

### 2. Object & Type Operations
- **`typeof`**: Used to determine the data type of a variable.
- **`Object.keys()`**: Retrieves an array of an object's keys.
- **`for...in`**: Loops through the enumerable properties of an object.
- **`delete`**: Removes a property from an object.
